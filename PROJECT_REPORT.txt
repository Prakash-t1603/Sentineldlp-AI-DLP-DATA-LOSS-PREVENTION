1. EXECUTIVE SUMMARY & ARCHITECTURAL OVERVIEW
================================================================================

SentinelDLP AI is an enterprise-grade, multi-channel Data Loss Prevention (DLP) 
and User & Entity Behavior Analytics (UEBA) platform. Designed for modern corporate 
enterprises, financial institutions, and regulated environments, the system detects, 
classifies, intercepts, and prevents unauthorized exfiltration of sensitive, 
proprietary, and regulated data across all primary workstation egress vectors:

  1. Removable USB Mass Storage Devices (Watchdog Real-Time Sensor + OS Mounts)
  2. Web Browsers & Cloud Storage (Google Drive, OneDrive, Dropbox, WhatsApp Web)
  3. Corporate Email & Webmail Attachments (Outlook, Gmail, RFC 822 MIME Streams)
  4. Workstation Clipboard & Local Monitored Filesystem Directories

The platform enforces a clean architectural separation between the Central DLP 
Server / SOC Dashboard and the distributed Employee Endpoint Agents.

2. SYSTEM ARCHITECTURE & TOPOLOGY
================================================================================

--------------------------------------------------------------------------------
2.1 CENTRAL DLP SERVER & SOC DASHBOARD (backend/ & frontend/)
--------------------------------------------------------------------------------
Runs on the central security server (bound to `0.0.0.0:8000` / `172.24.143.236:8000`):
  - FastAPI High-Performance REST API Gateway (/api/v1/...)
  - SOC Administrator Dashboard (HTML5, Vanilla CSS, Chart.js, Dark Theme)
  - Dedicated Employee Self-Service Portal (/employee-portal)
  - Natural Language Processing (NLP) & Regex Entity Classifier
  - Optical Character Recognition (OCR) Engine for Image Inspections
  - Centralized Multi-Factor Additive Risk Engine (0 - 100 Score)
  - DLP Policy Governance Engine (ALLOW / WARN / BLOCK)
  - Incident Response & Case Management System
  - Fleet Management Engine (Heartbeat Tracking, Status: ONLINE / WARNING / OFFLINE)
  - Central Database (SQLite WAL Mode / PostgreSQL Schema Parity)

--------------------------------------------------------------------------------
2.2 ENDPOINT MONITORING AGENT (agent/)
--------------------------------------------------------------------------------
Runs on employee workstations as a lightweight client daemon:
  - 100% Standalone: Zero database or backend module dependencies on the endpoint.
  - USB Storage Watchdog: Detects USB insertion, drive letters, and real-time copies.
  - Browser Receiver: HTTP server bound to `0.0.0.0:8765` (fallback: 8766-8768) to 
    receive DOM file upload interception events from browser extensions.
  - Clipboard Sensor: Intercepts clipboard copy operations for sensitive regex patterns.
  - Filesystem Watcher: Python Watchdog observer monitoring critical corporate folders.
  - Process Monitor: Detects unauthorized exfiltration utilities (curl, mega, tor, winscp).
  - Offline Fault Tolerance: Buffers events in local SQLite (`logs/offline_events.db`) 
    if Central Server is unreachable, auto-replaying upon reconnection.
  - Dynamic Heartbeats: Pings central server every 15s with system metrics & queue state.

--------------------------------------------------------------------------------
2.3 ENTERPRISE BROWSER EXTENSION (browser_extension/)
--------------------------------------------------------------------------------
Manifest V3 authorized extension installed in employee browsers (Chrome / Edge / Brave):
  - Intercepts file input clicks and drag-and-drop file drops before network transmission.
  - Extracts text snippets and transmits pre-flight telemetry to `http://172.24.143.236:8765` 
    (with direct fallback to `http://172.24.143.236:8000/api/dlp/browser-event`).
  - Displays instant in-browser toast alerts (`BLOCKED`, `WARNING`, `CLEAN`).
  - Automatically clears file input forms when transfers are blocked by policy.

3. CORE DLP CAPABILITIES & DETECTION CHANNELS
================================================================================

--------------------------------------------------------------------------------
3.1 REMOVABLE USB STORAGE WATCHDOG
--------------------------------------------------------------------------------
  - Continuously monitors removable storage insertion and mount events.
  - Intercepts file writes targeting USB drive letters (`E:\`, `F:\` on Windows, 
    `/media/*`, `/mnt/*` on Linux).
  - Computes SHA-256 hash, extracts document text, and classifies content.
  - Critical/High sensitivity transfers trigger instant BLOCK actions, alerting the SOC.

--------------------------------------------------------------------------------
3.2 WEB BROWSER & CLOUD STORAGE EGRESS
--------------------------------------------------------------------------------
  - Monitors high-risk egress websites: Google Drive, OneDrive, SharePoint, Dropbox, 
    Box, WhatsApp Web, Gmail Webmail, Outlook Webmail, WeTransfer, Mega.
  - Zero HTTPS Wire Decryption: Inspects files at the source browser DOM layer before 
    encryption, preserving HTTPS integrity and avoiding invasive root certificates.

--------------------------------------------------------------------------------
3.3 CORPORATE EMAIL & MIME ATTACHMENT INSPECTION
--------------------------------------------------------------------------------
  - Analyzes RFC 822 MIME email payloads and multipart attachments (.docx, .pdf, .csv).
  - Validates recipient domain whitelists (distinguishes internal vs external emails).
  - Blocks outgoing attachments containing unencrypted PII, financial info, or API secrets.

--------------------------------------------------------------------------------
3.4 WORKSTATION CLIPBOARD & LOCAL FILESYSTEM WATCHER
--------------------------------------------------------------------------------
  - Clipboard Monitor: Detects copy operations containing AWS keys, credentials, or PAN/Aadhaar.
  - Filesystem Watcher: Observes local directories, ignoring `.git`, `node_modules`, `.venv`.

4. CENTRAL SCANNING, NLP, OCR & CLASSIFIER ENGINES
================================================================================

1. Text & Document Extraction (`backend/services/file_analysis_service.py`):
   - Supports `.pdf` (`pypdf`), `.docx` (`python-docx`), `.txt`, `.csv`, `.json`, `.md`, `.env`.
   - Built-in size guards and multi-encoding fallback parsing.

2. Visual OCR Engine (`backend/services/ocr_service.py`):
   - Safely extracts text from `.png`, `.jpg`, `.jpeg`, `.bmp`, `.tiff` images via Tesseract/Pillow.
   - Guaranteed zero-crash fallback on non-image files or unconfigured environments.

3. Regex & NLP Entity Recognizer (`backend/services/nlp_service.py`):
   - AWS Access Keys (`AKIA[0-9A-Z]{16}`) & Secret Keys
   - Credit Card Numbers (Validated with Luhn Checksum Algorithm)
   - Indian Aadhaar Numbers (12-digit UIDAI format)
   - Indian Permanent Account Numbers (PAN: `[A-Z]{5}[0-9]{4}[A-Z]{1}`)
   - US Social Security Numbers (SSN: `\d{3}-\d{2}-\d{4}`)
   - Database Connection URIs (`postgres://`, `mysql://`, `mongodb://`)
   - Private Encryption Keys (`-----BEGIN RSA PRIVATE KEY-----`)
   - Corporate Confidentiality Markers (`STRICTLY CONFIDENTIAL`, `PROPRIETARY`)

4. SHA-256 Byte-Content Classifier (`backend/services/classifier_service.py`):
   - Content-addressed SHA-256 hash cache prevents redundant re-scanning of identical files.
   - Assigns 4-tier Classification:
     * `PUBLIC` (Sensitivity: 0 - 29)
     * `INTERNAL` (Sensitivity: 30 - 59)
     * `CONFIDENTIAL` (Sensitivity: 60 - 84)
     * `HIGHLY_CONFIDENTIAL` (Sensitivity: 85 - 100)

5. COMPOSITE RISK ENGINE & POLICY GOVERNANCE MATRIX
================================================================================

Additive Multi-Factor Risk Formula:
  Risk Score = Base Sensitivity (0 - 40)
             + Channel Weight (USB: +30, Cloud/Browser: +25, Email: +20)
             + Destination Multiplier (External/Untrusted: +15, Internal: +0)
             + Sensitive Entity Count Factor (0 - 15)
             + Process/Anomaly Surcharge (0 - 10)
  Total Risk clamped strictly to range [0.0, 100.0].

Risk Tiers & Policy Action Mapping:
--------------------------------------------------------------------------------
Risk Range      Risk Level       Default Policy Action    SOC Alert Trigger
--------------------------------------------------------------------------------
 0.0 - 29.9     LOW              ALLOW                    Audit Log Only
30.0 - 59.9     MEDIUM           ALLOW / WARN             Audit Log / Notice
60.0 - 84.9     HIGH             WARN / BLOCK             Alert + Investigation
85.0 - 100.0    CRITICAL         BLOCK                    Alert + Auto-Incident

11. COMPLIANCE, SECURITY HARDENING & DEFENSIVE CONTROLS
================================================================================

1. ZERO WIRE DECRYPTION:
   Inspects files at the source application DOM layer before transmission, avoiding 
   invasive root certificates, MITM latency, and HTTPS decryption liabilities.

2. CRYPTOGRAPHIC DEVICE TOKENS:
   Workstations authenticate using unique provisioned device tokens (`Bearer dev-tok-...`), 
   preventing cross-device spoofing or token replay.

3. OFFLINE FAULT TOLERANCE:
   Endpoint agent buffers events in local SQLite during network disruptions, ensuring 
   zero telemetry loss upon reconnection.

4. REAL-TIME CLEAN ALERT BASELINE:
   Alerts and incidents are strictly generated from genuine live endpoint activity 
   (USB copy, cloud upload, clipboard exfiltration), eliminating fake/demo clutter.

5. REGULATORY ALIGNMENT:
   - GDPR Article 32 (Security of Processing & Data Protection)
   - HIPAA Security Rule §164.312 (Technical Safeguards & PHI Egress Controls)
   - PCI-DSS Requirement 3 (Cardholder Data Protection & Luhn Verification)
   - ISO/IEC 27001 Annex A.8.12 (Data Leakage Prevention Controls)
